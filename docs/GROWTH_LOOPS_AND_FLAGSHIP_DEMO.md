## Flagship demo standard

A Spielberg-level presentation should not show a feature list. It should show one unforgettable scene:

- Paste one-page scene
- Generate verified beat and shot breakdown
- Generate 12-16 cinematic storyboard panels
- Generate 30-60 second animatic with scratch voice/music/SFX
- Show prompt correction before/after
- Export director package
- Share/remix link
- Rights receipt

The purpose is to create immediate emotional proof and conversion.
