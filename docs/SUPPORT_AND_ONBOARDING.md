# Support and Onboarding

Revenue SaaS requires user trust after checkout.

## Add these flows

- Welcome email after signup
- Billing receipt email
- Generation completed email
- Failed generation + token refund email
- Upgrade confirmation
- Cancel confirmation
- Help center
- Contact support form
- In-app feedback button
- Tutorial for first 10-second storyboard

## Support categories

- Billing issue
- Token issue
- Generation failed
- Export failed
- Account/login issue
- Copyright/rights question
- Feature request
