# Billion-Dollar Platform Roadmap

## Strategic goal
Make CineLoom the fastest way to turn any script into a professional storyboard, animatic, and pitch package that creators can share, sell, and produce.

## Platform pillars

1. Magic output engine: one page of script to storyboard + animatic + export package.
2. Viral free-to-paid funnel: watermarked free 10-second storyboard, public share, remix, upgrade.
3. Enterprise trust: SSO, audit logs, private storage, IP receipts, training opt-out.
4. Usage and API revenue: subscriptions, tokens, API products, team seats, enterprise contracts.
5. Marketplace ecosystem: templates, styles, shot packs, voices, music cues, plugins.
6. Film integrations: Final Draft, Fountain, Frame.io, Premiere, Resolve, ShotGrid, Monday.com.
7. Data moat: CineLoom workflow graph from script line to beat, shot, panel, correction, export, and QA.

## Phases

- v3.3: Platform ecosystem readiness.
- v3.4: Live execution provider connections.
- v3.5: Paid beta with free-to-paid funnel.
- v4.0: Enterprise pilots and private studio workspaces.
- v5.0: Marketplace + API platform scale.
