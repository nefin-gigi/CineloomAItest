# CineLoom v3.3 — Billion-Platform Release Notes

Version 3.3 adds the platform layer needed beyond a storyboard SaaS:

- Public Platform page
- Marketplace page and marketplace template API
- Developer API platform page and metered API route contracts
- Enterprise trust page and trust-report API
- Film integrations page and integration contracts
- Public share/remix page and growth APIs
- Referral engine scaffold
- Flagship 60-second demo spec
- Super Admin platform ecosystem controls
- Database migration for marketplace, API keys, public shares, remixes, referrals, trust controls, film integrations, and rights receipts
- Environment variables for marketplace, API platform, enterprise trust, integrations, referrals, and flagship demo endpoints

This package is still endpoint-driven: external services plug into the Super Admin connector and execution endpoint layer.
