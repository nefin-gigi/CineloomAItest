# CineLoom.ai v2.0 Release Notes

## Release goal

Version 2.0 is tuned for a high-impact Hollywood director, producer, investor, indie filmmaker, and film enthusiast demo. The target is to make every previous ranking category cross the 9.5/10 private-demo threshold.

## Improvements

1. **One-click guided demo**
   - New `DirectorDemoExperience` component.
   - Consolidates the story-to-screen journey into one page.

2. **Premium storyboard proof**
   - Added eight local cinematic SVG storyboard frames.
   - Replaced empty placeholders on the static storyboard page.

3. **Playable animatic simulator**
   - Added interactive playback progress and frame stepping.
   - Demonstrates timing, movement, dialogue, music, and SFX planning.

4. **One-click export simulator**
   - Shows director package generation feedback.
   - Previews storyboard PDF, animatic preview, shot list, prompt JSON, character/location bible, and QA report.

5. **Director-friendly navigation**
   - Primary nav now leads with Director Mode.
   - Advanced tools are still available but no longer dominate first impression.

6. **Real-feeling actions**
   - Workflow buttons now update feedback text.
   - Demo buttons log actions and show successful states.

7. **Customer scorecard**
   - Dashboard and QA center show explicit v2 scoring targets and experience boosters.

## Honest production status

This is demo-ready and Vercel-ready. It is not yet a fully connected production AI movie engine. Real provider integrations, persistence, storage, and export rendering remain the next engineering workstream.
