# Storyboarding and Cinematography References

The workflow was designed around the references discussed for CineLoom.ai:

- StudioBinder Save the Cat / beat-sheet references
- StudioBinder storyboard rules
- 5 Cs of Cinematography
- ASC cinematography manual references
- Cinematography: Theory and Practice
- Master Shots Vol. 1, 2, and 3
- Professional Storyboarding: Rules of Thumb by Sergio Paez and Anson Jew
- Storyboards: Motion in Art by Mark Simon

## How these references map to product features

- Beat Breakdown → story structure and continuity verification
- Shot Design → camera angle, lens, movement, composition, geography
- Static Storyboard → production visual planning
- Dynamic Storyboard / Animatic → timing, motion, voice, music, rough cut
- Auto QA → 180-degree rule, screen direction, eyeline, prop continuity, missing panels
