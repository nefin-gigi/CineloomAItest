# SaaS Operating Model for the Film Industry

CineLoom should operate as a film pre-production SaaS with six pillars.

1. Acquire: SEO, examples, public share pages, referral credits, marketplace content.
2. Activate: free 10-second storyboard, first-project wizard, guided demo, sample scripts.
3. Monetize: subscriptions, token packs, clean exports, team seats, enterprise contracts, API usage.
4. Retain: saved projects, monthly token refresh, templates, version history, review workflows.
5. Scale: endpoint execution, queues, rate limits, provider routing, Super Admin health checks.
6. Protect: private storage, SSO, audit logs, IP receipts, data retention and safety controls.

The v3.4 package adds public pages, APIs, data model, and Super Admin surfaces to operate all six pillars.
