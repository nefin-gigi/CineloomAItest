# Enterprise Security and Compliance Pack

This package provides the product surfaces and database model for an enterprise trust layer.

## Required controls
- SSO/SAML and SCIM endpoint contracts.
- Workspace RBAC.
- Private project mode.
- Private object storage and signed URLs.
- Audit logs for generation, approval, export and admin actions.
- Data retention policy and deletion workflow.
- Model-training opt-out.
- IP rights receipt for each project/export.
- Security event logging and incident runbook.
- Subprocessor register placeholder.
- SOC 2 readiness roadmap.

## Studio buyer concerns
- Are scripts used to train models?
- Who can access the project?
- Can a project be deleted?
- Where are assets stored?
- Can exports be watermarked and controlled?
- Is there an audit trail?
