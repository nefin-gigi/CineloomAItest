# API Platform and Marketplace

## API products

- Script-to-Beats API
- Script-to-Shots API
- Storyboard Generation API
- Animatic Rendering API
- Continuity QA API
- Export Package API

Each API should support:

- API keys
- scopes
- rate limits
- idempotency keys
- usage events
- metered billing
- webhook callbacks
- enterprise private endpoints

## Marketplace products

- Genre templates
- Shot packs
- Visual style packs
- Audio prompt packs
- Export templates
- Character/location packs
- Education packs

## Marketplace controls

- seller onboarding
- review workflow
- payouts
- commission rate
- purchase history
- license metadata
- template usage analytics
