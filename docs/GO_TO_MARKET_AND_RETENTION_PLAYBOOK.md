# Go-to-Market and Retention Playbook

## Primary funnel
Visitor → Free 10-second storyboard → Watermarked result → Signup → Token or subscription purchase → Prompt correction → Clean export → Return for bigger project.

## Conversion triggers
- Free result generated.
- User tries clean export.
- User runs out of tokens.
- User creates second project.
- User invites collaborator.
- User requests private project mode.

## Retention triggers
- Monthly token refresh.
- New template pack announcement.
- Project inactivity reminder.
- New export format announcement.
- Creator challenge or referral credit.

## Priority customer niches
- YouTube Shorts creators.
- Indie filmmakers.
- Faith-based media teams.
- Film schools.
- Ad agencies.
- Production pitch teams.
