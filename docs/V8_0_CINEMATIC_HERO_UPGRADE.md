# CineLoom v8.0 Cinematic Hero Upgrade

This release upgrades only the public homepage hero while preserving all existing backend, security, Super Admin, endpoint-router, AI Harness, low-token workflow, and responsive layout fixes.

## Design goals

- More cinematic look and feel without crowding the page.
- Premium SaaS layout with a clear hero message and obvious CTA.
- Film-style storyboard preview with a large selected board, film-strip thumbnails, and low-token AI Harness messaging.
- Responsive layout that prevents text overlap on staging and production.
