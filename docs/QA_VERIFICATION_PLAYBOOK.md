# QA Verification Playbook

## Script QA

- Scene headings detected.
- Locations are clear.
- Time of day is captured.
- Dialogue is linked to characters.
- Runtime estimate is available.
- Character and location extraction is traceable to script lines.

## Beat QA

- Save-the-Cat style beat coverage.
- Beat-to-scene mapping.
- Missing beat warnings.
- Weak beat warnings.
- Character arc alignment.
- Runtime/page position check.
- Human approval gate.

## Shot QA

- 5 Cs coverage: camera angles, continuity, cutting, close-ups, composition.
- Shot purpose is clear.
- Lens and movement are motivated.
- 180-degree axis is preserved.
- Eyelines are stable.
- Props and wardrobe continuity are maintained.

## Storyboard QA

- Each approved shot has a panel.
- Panel prompt includes shot grammar, style, aspect ratio, character continuity, and location continuity.
- Character face/wardrobe/prop consistency is locked.
- Style consistency is maintained.
- Director comments are resolved.

## Animatic QA

- Panel durations match scene intention.
- Motion is clear.
- Dialogue sync exists.
- Music and SFX cues are present.
- Aspect ratio and frame rate are locked.

## Video Handoff QA

- Export package complete.
- Provider settings complete.
- Cost estimate generated.
- Real provider keys exist before queuing production jobs.
