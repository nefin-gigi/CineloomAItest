# AI Provenance and Safety Governance

Every generated asset should have a provenance record.

## Required provenance fields

- Asset ID
- Project ID
- Workspace ID
- Generation stage
- Prompt version ID
- Provider
- Model version
- Seed
- Input hash
- Output hash
- Token cost
- Provider cost
- Safety status
- Rights status
- Training opt-out flag
- Commercial-use flag

## Safety governance

CineLoom should evaluate:

- Prompt injection attempts in uploaded scripts
- Public figure/likeness risk
- Copyrighted character/style imitation risk
- Violent or harmful content requests
- Minors and sensitive subject matter
- Script ownership attestation
- Model-training opt-out compliance

## Enterprise requirement

Studios and production companies need a traceable chain for how an asset was created, what prompt/model/provider generated it, and whether it is licensed for commercial use.
